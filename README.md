# sql-delivery-analytics

Этот проект имитирует систему аналитики доставки еды с использованием SQL.

---

## Цели проекта

- Анализ эффективности доставки
- Измерение времени доставки
- Определение лучших курьеров
- Анализ работы ресторанов
- Отслеживание выручки

---

## Данные (Dataset)

- orders (заказы)
- couriers (курьеры)
- restaurants (рестораны)

---

## Основные инсайты

- Расчёт среднего времени доставки
- Сравнение быстрых и медленных доставок
- Топ-курьеры по количеству доставок
- Самые популярные рестораны
- Динамика выручки по дням

---

## Технологии

- SQL (совместим с PostgreSQL)
- Проектирование баз данных
- Аналитические запросы

---

## Как запустить проект

1. Создать базу данных  
2. Выполнить файл `01_create_tables.sql`  
3. Загрузить данные через `02_insert_data.sql`  
4. Запустить аналитические запросы из `03_analysis.sql`
